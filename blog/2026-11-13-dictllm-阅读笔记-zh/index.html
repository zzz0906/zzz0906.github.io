    DictLLM 阅读笔记：共享字典、稀疏系数与低比特压缩

    笔记日期： 2026-11-13（UTC）
    作者： Zhongzhu Zhou
    所读论文： DictLLM: Post-training Compression of Large Language Model with Dictionary Kernels
    论文作者： Jinho Park、Se Young Chun、Mingoo Seok
    arXiv： 2611.08082v1，2026-11-05

    先看清楚：究竟在共享什么

    压缩两个相邻的 Transformer 层时，可以分别做低秩分解，也可以让两个层用同一组输入方向，但允许它们以不同的方式组合这些方向。第二种做法就是这篇论文的起点：用一个共享字典存下组内共用的方向，每层仍保留自己的系数矩阵。每个输出只用一部分字典项时，字典可以比单靠低秩压缩时更宽。论文再做一步很实用的修补：系数剪完以后，把这些系数固定住，重新拟合一次字典。最后，两类因子分别量化。

    阅读时我把摘要和附录的两组数字分开记。约 5.1 倍是按论文的投影参数与 NVFP4 格式口径计算的表示压缩；相应的 WikiText-2 困惑度从 5.68 到 8.48。1.24 倍则来自附录 A8 的 FP16 解码计时，在指定 GPU、批大小为 1、有稀疏后端且不计预填充的条件下成立。两者回答的问题分别是「能表示得多小」和「这一套执行路径快了多少」。全文 24 页及附录 A1 至 A10 都纳入本笔记。下面的小矩阵是我用来检查推导的算例，模型和硬件结果均来自论文。

    图 1：依据原文第 3 节自绘。剪枝改变了每个输出列能够访问的字典项；重拟合在支撑固定后重新寻找共享方向。

    前置知识：把投影拆成两次乘法

    设一层的输入 XℓX_\ellXℓ​ 每行对应一个 token，权重 WℓW_\ellWℓ​ 的形状为 din×doutd_{\rm in}\times d_{\rm out}din​×dout​。原始层输出是 XℓWℓX_\ell W_\ellXℓ​Wℓ​。按论文的矩阵方向，字典 DgD_gDg​ 的每列都是一个输入方向，系数 CℓC_\ellCℓ​ 的每列说明一个输出通道如何组合这些方向。组 ggg 的字典宽度记为 kkk：

    Wℓ≈DgCℓ,Zℓ=XℓDg,Yℓ≈ZℓCℓ.(1)W_\ell\approx D_g C_\ell,\qquad Z_\ell=X_\ell D_g,\qquad Y_\ell\approx Z_\ell C_\ell. \tag{1}Wℓ​≈Dg​Cℓ​,Zℓ​=Xℓ​Dg​,Yℓ​≈Zℓ​Cℓ​.(1)

    共享的是 DgD_gDg​ 的参数。即使两层先后执行，输入也已经被中间的注意力、残差或非线性改变，两层的 ZℓZ_\ellZℓ​ 不能互用。共享能够减少静态容量；能不能少从显存读取一次，还取决于字典在两次访问间能否留在较快的存储层。部署若把两因子预先乘回完整矩阵，便失去这条节省路径。两次乘法也可能增加一次中间特征的写回。

    图 2：依据论文图 2 自绘。箭头表示两个层各自的计算流程；两个 D 方框指同一份参数。

    低秩和稀疏是两道不同的限制。低秩规定所有输出列都落在同一个至多 kkk 维的子空间。稀疏规定每个输出列在这个子空间里只准选少量字典项，列与列可以选不同的项。四个字典项的两个输出列分别用第 1、3 项与第 2、4 项，仍然可以在整张系数矩阵中覆盖四项。系数中的零通常不会在乘回权重后仍是零。做部署估算时，要数稀疏乘法真正访问的系数，而不是按还原权重的零值数推断。

    SVD 的作用是从许多方向中找出值得保留的方向。普通截断 SVD 在 Frobenius 平方误差下选最大的 kkk 个奇异值，剩余奇异值的平方和就是最优误差。权重误差不一定等价于输出误差。例如一批输入的两个通道总是一起变化，把某输出的第一个权重加一点、第二个减一点，模型在这批输入上的输出可以完全不变。这正是输入统计有用的原因。写成矩阵，若某一列误差为 rrr，它造成的输出平方误差是 r⊤Xℓ⊤Xℓrr^\top X_\ell^\top X_\ell rr⊤Xℓ⊤​Xℓ​r。论文称 Sℓ=Xℓ⊤XℓS_\ell=X_\ell^\top X_\ellSℓ​=Xℓ⊤​Xℓ​ 为输入协方差，这里是未经中心化的二阶矩；减去均值会改变要保持的输出。

    还要区分三种预算。第一种按非零参数计数，方便推导该选多大秩。第二种数真实字节，要算量化尺度、掩码、稀疏索引、补齐和未压缩的嵌入及输出头。第三种是延迟或吞吐，除了读权重，还要算索引访问、写中间结果和调度开销。第一种预算下的胜利不能直接折算为第三种。

    从参数预算反推字典宽度

    先只看一组形状相同的 nnn 个投影。压缩前共有 ndindoutn d_{\rm in}d_{\rm out}ndin​dout​ 个权重值。字典存一份，占 dinkd_{\rm in}kdin​k；每层系数占 kdoutkd_{\rm out}kdout​，剪去比例 ppp 后只计保留的值。于是

    N0=ndindout,Np=dink+n(1−p)kdout,ρ=1−Np/N0,G=N0/Np.(2)\begin{aligned} N_0&=n d_{\rm in}d_{\rm out},\\ N_p&=d_{\rm in}k+n(1-p)kd_{\rm out},\\ \rho&=1-N_p/N_0,\qquad G=N_0/N_p. \end{aligned} \tag{2}N0​Np​ρ​=ndin​dout​,=din​k+n(1−p)kdout​,=1−Np​/N0​,G=N0​/Np​.​(2)

    ρ\rhoρ 是削减比例，GGG 是原大小除以压缩后大小。若只做分解，还没剪枝，就令 p=0p=0p=0。把目标削减比例 ρfac\rho_{\rm fac}ρfac​ 移到等式左边，剩下的预算等于 k(din+ndout)k(d_{\rm in}+nd_{\rm out})k(din​+ndout​)，解出：

    k=⌊(1−ρfac)ndindoutdin+ndout⌋.(3)k=\left\lfloor\frac{(1-\rho_{\rm fac})n d_{\rm in}d_{\rm out}} {d_{\rm in}+nd_{\rm out}}\right\rfloor. \tag{3}k=⌊din​+ndout​(1−ρfac​)ndin​dout​​⌋.(3)

    这条式子很适合拿 LLaMA-7B 的形状检查。4096 宽的方形 Q 投影，分解先减 20%，独立分解时可选秩 1638；两层共享可选 2184。两层情形下，忽略取整误差，字典占分解后参数的三分之一，系数占三分之二。所以剪掉 19.4% 系数，只会额外削减压缩前组大小的约 0.8×2/3×0.194=10.35%0.8\times 2/3\times 0.194=10.35\%0.8×2/3×0.194=10.35%，最后共减少约 30.35%。附录 A1.2 给出的 Q、K、V 约 30.36%。形状为 11008×409611008\times409611008×4096 的 down 投影单独分解，同样的 20% 先减预算只给秩 2388。即便统一使用 ppp，各类投影的最终削减比例也不同；不能把某个 Q 层的数字当成整个模型的比例。

    图 3：由式（2）和（3）计算的方阵示意，固定分解削减 20%。右图只计非零值；索引、尺度和其他固定部分另算。

    组越大，每个参与层分摊的字典成本越低，但这条曲线很快变平。方形投影的秩比例是 (1−ρfac)n/(n+1)(1-\rho_{\rm fac})n/(n+1)(1−ρfac​)n/(n+1)，组大小从 1 变 2 相当有用，从 8 变 16 的新增空间少得多。相比之下，多拉几层进组可能带进截然不同的激活方向。原文把输出投影和 down 投影通常留为独立字典。附录 A6 特意改变这点，把组扩大到 4、8、16，固定字典秩并剪掉 60% 系数，再对全部投影做 LoRA。论文报告 2.9、3.5、3.9 倍对应 10.26、12.32、15.89 的困惑度。这个附加实验说明更强共享有路可走，也显示了质量代价，并不能算作主流程的无微调结果。

    秩选定以后，剪系数还有一个下限：即便极端地把所有系数都删除，字典本身也要留下。刚才的两层方阵至少还要保存原值数约 26.67% 的字典，何况那时已经没有有用输出。这个下限在输入很宽、输出很窄时更明显。实际配预算时，我会优先在共享收益较大且激活误差小的投影上做组内摊销，然后针对其他层单独选秩和稀疏率。

    第一步：在输入度量下分解

    原文式（2）表达的是逐层输出误差。设 Rℓ=Wℓ−DgCℓR_\ell=W_\ell-D_g C_\ellRℓ​=Wℓ​−Dg​Cℓ​，将 WℓW_\ellWℓ​ 与 CℓC_\ellCℓ​ 分别按列拼成 WgW_gWg​ 和 CgC_gCg​。初始化的做法是用组内输入二阶矩的和 Sg=∑ℓSℓS_g=\sum_\ell S_\ellSg​=∑ℓ​Sℓ​，给拼在一起的所有权重列使用同一个度量。写出来就能看到原目标和计算时用的近似差在哪：

    算法 1：用固定逆矩阵分块剪系数

    以下按论文算法 2 改写。列块负责组织计算；每个输出列独立排序。块开始时排好顺序，实际补偿用当前系数，最后统一施加掩码。

    1. Form P from the damped coefficient Gram; read its diagonal.
2. Split output columns into blocks of at most B columns.
3. In each column sort rows by c[i]^2 / P[i,i], lowest first.
4. Mark the first floor(p*k) rows in that order.
5. For every marked row i, read the current value c[i].
6.     Subtract P[:,i] * c[i] / P[i,i] from the column.
7. Apply the mask: all marked coefficients become exact zeros.

    若一次删除集合 JJJ，用 EJE_JEJ​ 收集被删坐标的单位向量，把标量约束换成 EJ⊤δ=−cJE_J^\top\delta=-c_JEJ⊤​δ=−cJ​。一阶条件给出 δ=−PEJμ\delta=-PE_J\muδ=−PEJ​μ，约束确定乘子，得到

    δJ⋆=−PEJ(EJ⊤PEJ)−1cJ,sJ=cJ⊤(EJ⊤PEJ)−1cJ.(8)\delta_J^\star=-PE_J(E_J^\top PE_J)^{-1}c_J,\qquad s_J=c_J^\top(E_J^\top PE_J)^{-1}c_J. \tag{8}δJ⋆​=−PEJ​(EJ⊤​PEJ​)−1cJ​,sJ​=cJ⊤​(EJ⊤​PEJ​)−1cJ​.(8)

    这也说明固定逆矩阵的逐项修正为什么未必等于一次联合求解。对非对角情形，删后面一项可能重新挪动前面已经清零的值。最终硬掩码保证可行，但恢复可行不等于找到了给定支撑下的最优点。可以按保留子空间重算逆，也可以选定支撑后解一次多约束问题；两者都增加离线成本。表 3 的对照里，两种 Hessian 方法的 PPL 都四舍五入到 9.89；全量求逆 13.49 小时，固定逆更新 55.6 分钟，复算比值约 14.56。单靠幅度的 44.6 分钟更短，但 PPL 为 47.43。这是一次指定设置的离线时间与质量比较。

    第三、四步：把字典拟合到剩下的系数

    剪完以后，把各层系数拼成 C~\widetilde CC，其中的数值与零都冻结。现在只求 DDD。对使用共同左度量的目标求导，梯度是 2Sg(DC~−Wg)C~⊤2S_g(D\widetilde C-W_g)\widetilde C^\top2Sg​(DC−Wg​)C⊤。如果 SgS_gSg​ 正定，令梯度为零就能从左边消去它。为避免有些字典项完全闲置时的奇异性，可对右边的系数 Gram 加阻尼：

    Drefit(C~C~⊤+λI)=WgC~⊤.(9)D_{\rm refit}(\widetilde C\widetilde C^\top+\lambda I) = W_g\widetilde C^\top. \tag{9}Drefit​(CC⊤+λI)=Wg​C⊤.(9)

    这等价于在经过输入变换的坐标中做岭回归，或者在加权残差旁惩罚 ∥Sg1/2D∥F2\|S_g^{1/2}D\|_F^2∥Sg1/2​D∥F2​。如果改成直接惩罚未变换的 ∥D∥F2\|D\|_F^2∥D∥F2​，一般会得到不同的方程。若保留逐层不同的度量，令各层梯度相加也会变成另一个问题：

    ∑ℓ∈gSℓDC~ℓC~ℓ⊤=∑ℓ∈gSℓWℓC~ℓ⊤.(10)\sum_{\ell\in g} S_\ell D\widetilde C_\ell\widetilde C_\ell^\top = \sum_{\ell\in g} S_\ell W_\ell\widetilde C_\ell^\top . \tag{10}ℓ∈g∑​Sℓ​DCℓ​Cℓ⊤​=ℓ∈g∑​Sℓ​Wℓ​Cℓ⊤​.(10)

    这是不加阻尼的驻点式。不同的 SℓS_\ellSℓ​ 不能从求和里统一消去。式（9）省事，足以作为逐层拟合的起点；如果有一层在合并度量下始终吃亏，可以考虑迭代解式（10），而不改变线上张量形状。

    用一个小例子直观地算一遍。目标权重的三列依次是 (3,1)(3,1)(3,1)、(1,2)(1,2)(1,2)、(2,1)(2,1)(2,1)。系数矩阵的三列是 (1,0)(1,0)(1,0)、(0,2)(0,2)(0,2)、(1,0)(1,0)(1,0)。以单位阵为字典时误差平方和为 8。固定系数后，第一列字典同时服务第 1、3 个输出，因此取两列目标的均值 (2.5,1)(2.5,1)(2.5,1)；第二列字典只服务第 2 个输出，取该目标的一半 (0.5,1)(0.5,1)(0.5,1)。相乘后只剩第 1、3 个输出各 0.5 的首坐标误差，总平方误差降为 0.5。我用矩阵乘法也核对了这个结果。压缩格式不必多存一个系数。

    算法 2：从稠密投影生成可部署的因子

    对应论文算法 1。量化字典时看原始输入；量化系数时看字典变换后的输入。论文算法把剪枝阶段的系数度量传给量化，若用重拟合后的字典重新算度量，应作为单独的对照。

    1. Collect input Gram matrices with the original model.
2. Group compatible projections by type; sum input Grams.
3.     Set k from the dense factor budget.
4.     Factor scaled weights and split coefficients by layer.
5.     Form the dictionary-induced Gram for coefficients.
6.     Prune each coefficient matrix using Algorithm 1 here.
7.     Freeze sparse coefficients and refit the dictionary.
8.     Quantize the dictionary with its input Gram.
9.     Quantize coefficients with their Gram and fixed mask.
10.    Store the factors, scale data and coefficient support.

    量化误差也不是简单地把两份误差加起来。写 D^=D+ΔD\widehat D=D+\Delta DD=D+ΔD、C^=C+ΔC\widehat C=C+\Delta CC=C+ΔC，减掉原分解的输出得到

    X(D^C^−DC)=XΔDC+XDΔC+XΔDΔC.(11)X(\widehat D\widehat C-DC) =X\Delta D C+XD\Delta C+X\Delta D\Delta C. \tag{11}X(DC−DC)=XΔDC+XDΔC+XΔDΔC.(11)

    对字典而言，X⊤XX^\top XX⊤X 描述误差的输入侧，但末端还有由系数决定的右侧权重。对系数而言，输入是 XDXDXD，其 Gram 正是系数度量。两者一起量化，还会有第三项和各项之间的相互抵消或放大。分别处理的价值在于每次只面对一个可解的子问题。原文用 NVFP4 的组内尺度表示两种因子，并把系数掩码固定为零；附录 A2 给出掩码量化的相对阻尼 0.1。这个近似值得和「先量化字典，再按新字典修正系数的尺度与误差」作对照。

    局限：这些数字能回答哪些问题

    原文附录 A10 明确指出，系数的非结构化稀疏要求后端处理不规则访问。它确实给出了一个可用的 FP16 路径，但没有提供 NVFP4 稀疏路径的端到端解码实测，也没有手机能耗测量。表 A14 的短提示、单序列和固定生成步数不足以说明持续批处理、长上下文或首 token 延迟。新设备要重新核对精度支持、低比特稀疏能否结合、字典留在缓存的概率，以及两次矩阵乘法之间有没有额外写回。单看权重容量无法回答这些问题。

    校准还有另一层限制。论文的共享空间是在稠密模型、同一语料的短段上学出来的。部署中代码、中文、长提示和模型自己生成的历史可能给出不同的输入统计。某个低频方向只占很小的平均谱能量，仍可能在专门任务中决定结果。逐层激活重建也不包含下游层会如何放大误差。零样本任务均值适合比较表内设置，却可能掩盖单个任务退化；表里较小的差距也没有跨随机种子或逐样本的不确定性估计。

    批判性分析：怎样把优势拆成可检验的假设

    先评估两层值不值得放在一组

    相邻不保证输入统计一致，也不保证两个投影的主方向可共用。可以用一个反例判断式（4）里的差别有多大。设第一层的单输出权重为 (1,0)⊤(1,0)^\top(1,0)⊤，第二层为 (0,2)⊤(0,2)^\top(0,2)⊤，校准二阶矩分别是 9I9I9I 和 III。若字典只保留第一坐标，拟合完逐层系数后第二层的误差是 4；只留第二坐标则第一层误差是 9。逐层度量会偏向第一坐标。合并成 10I10I10I 后，两种选择的误差变成 40 和 10，排序颠倒。原因是第二层的残差也被第一层的输入能量放大了。这个例子只比较两种字典候选，已经足以说明合并度量可以改变选择。

    实用改法是先在留出的样本上比较成组与独立的拟合残差，而且按每层单列结果。光看组平均会让代价大的单层被掩盖。我会同时记最差层和逐 token 残差高分位，先找出哪些层适合共享；再在固定打包字节数的条件下比较相邻配对、按误差选择配对和私有字典。第一轮保持量化和掩码形式一致，以便把共享收益与格式收益分开。若跨层输入分布差异很大，可保留私有字典，或者在式（9）初始化后少量迭代逐层目标。这样做的收益是避免组内高能量层替另一层决定方向，代价是更多离线计算以及可能降低字典复用。

    识别二阶打分里真正起作用的部分

    我最想看到的对照是把「分数有权重」和「删项后补偿其他系数」拆开。第一组保持同一个新分解的字典，同一个剪枝比例，不重拟合，比较普通幅度和按 Σk2\Sigma_k^2Σk2​ 加权的幅度。第二组换为逐层度量，先量非对角项的大小，再对同一掩码比较直接置零、固定逆补偿、以及给定支撑后精确重解。第三组再统一重拟合字典，测前两组差距是否被重拟合吸收。若理想池化度量下几种补偿方案几乎一样，就没必要为逆矩阵更新支付太多成本；若逐层度量显著改善困难样本，才值得保留更多局部统计。

    同一个分解乘积内部还可以换坐标。任意可逆 AAA 都有 (DA)(A−1C)=DC(DA)(A^{-1}C)=DC(DA)(A−1C)=DC。对角缩放不会改零的位置，而且在无阻尼的理想二次问题里，删项代价保持不变：PiiP_{ii}Pii​ 和 ci2c_i^2ci2​ 随尺度以相同的平方倒数改变。但真实的阻尼和每块共享的量化尺度不具备这种不变性。一组字典列被放大后，其系数可相应缩小；两边的动态范围却会改变。一般旋转还会改变哪些位置容易剪成零。一个有意义的改进是先保持稠密乘积不变，再选尺度或受限旋转，让掩码和量化格点更合适。不能只看字典误差；某一侧被调得更平衡，另一侧可能新生离群值。可以用留出激活上的联合输出误差决定是否接受换坐标。

    让部署布局参与决定掩码

    如果设备只对某种块稀疏有高效支持，先生成任意掩码再打包可能走不通。更直接的替代是剪枝时就约束支撑，再用同一个字典重拟合修补精度。受限掩码的选择空间更小，可能在相同非零数下更差；按真实字节数和内核耗时比较，结果却可能反过来。应加入带原生低比特算子的稠密基线、已测过的 FP16 非结构化路径和候选的结构化路径。先比较同字节预算下的质量，再比较同质量下的延迟，避免只挑一种有利口径。

    要判断「跨层共享」本身给执行带来多少好处，还可以固定压缩权重与布局，只切换字典能否驻留在较快存储中，报告字典流量和中间特征写回量。如果权重文件变小而每层依然重新从显存加载字典，性能收益应归因于其他因素。最好分别看方形 Q 投影、较窄的 K/V 以及 FFN 大矩阵，因为它们的读写比例不同。最后再把小批短提示扩成多个预填充长度和并发点，单列首 token、后续 token 和峰值显存。只有实际做了板卡或整机计量，才可以把吞吐优势写成能耗优势。

    用可量化的条件检查校准能不能外推

    共同度量在训练语料上拟合得好以后，下一步不是重新画一张奇异值图，而是问上线输入是否仍然给相近的残差排序。设同一个投影残差矩阵是 RRR，校准、目标输入的二阶矩分别是 ScalS_{\rm cal}Scal​ 和 StgtS_{\rm tgt}Stgt​。可以先在实际使用的输入子空间里把目标二阶矩写成 Scal1/2AScal1/2S_{\rm cal}^{1/2} A S_{\rm cal}^{1/2}Scal1/2​AScal1/2​。具体做法是对目标矩阵左、右各乘一次 Scal−1/2S_{\rm cal}^{-1/2}Scal−1/2​ 得到 AAA。若校准矩阵正定，或者明确只谈其正定支撑，而目标在该支撑内没有超出，那么 AAA 的最大和最小特征值给出误差转移范围。令 T=Scal1/2RT=S_{\rm cal}^{1/2}RT=Scal1/2​R，目标误差变为 tr⁡(T⊤AT)\operatorname{tr}(T^\top A T)tr(T⊤AT)。对 TTT 的每列施加 Rayleigh 商上下界，再按列相加，就得到

    λmin⁡(A)∥T∥F2≤tr⁡(T⊤AT)≤λmax⁡(A)∥T∥F2.(13)\lambda_{\min}(A)\|T\|_F^2 \leq \operatorname{tr}(T^\top A T) \leq \lambda_{\max}(A)\|T\|_F^2 . \tag{13}λmin​(A)∥T∥F2​≤tr(T⊤AT)≤λmax​(A)∥T∥F2​.(13)

    这个界解释了「校准误差小」何时是有用的证据：若目标二阶矩在所有相关方向上最多是校准度量的两倍，则目标重建误差也至多两倍。若最大的广义特征值很大，平均 PPL 之外就要看目标流量中具体哪类输入放大了哪些方向。若目标有校准完全没见过的方向，有限上界根本不成立。比如校准输入只有第一通道，残差完全落在第二通道；校准误差是零，一上线出现第二通道输入，目标误差可以任意大。给校准矩阵加阻尼可让计算有定义，但不等于这个方向已经得到统计支持。阻尼很小、目标权重很大时，得到的上界依然可能没有约束力。

    我会用两级检查代替只比校准样本数。先选几个业务切片，在保留方向与丢弃方向上分别估计激活能量，再选高风险投影做留出重建。直接估全部广义特征值可能昂贵；可以先在高残差的列方向及字典的正交补里作探测。第二级再用相同切片看任务是否失败，区分「输出误差大但任务不敏感」和「低能量方向恰好决定某个决策」。输入统计只能界定线性误差，不会给最终任务成功率界；量第二级是为了检验下游残差放大和模型自身生成分布的变化。这个流程适合发现在哪些层该加秩，或者保留少数高风险输出的全精度残差，而不必把整个组都拉回稠密权重。

    还可以把同样的思想用于重拟合的验收。先冻结系数支撑与校准规模，分别解共同度量的式（9）和逐层度量的式（10）。比较时保存各自拟合集残差与留出集残差，把代价高的逐层求解作为离线参照，而非默认替换。若逐层拟合只在拟合集改善，增加校准多样性可能比换求解器有效；若它在留出集尤其是最差层也改善，才有理由为各层维护不同的二阶矩。字典重拟合的成功标准可因此写得更具体：不增加打包预算、不改掩码，在指定留出切片上降低残差，并且不让原本已接近质量底线的层变坏。

    给定掩码以后，允许系数重新拟合吗

    原文的第三步保持系数值不动，只解共享字典。另一个自然选择是保留零的位置，却允许非零系数在新字典下再拟合一次。设一个输出列的稠密目标是 www，允许使用的字典子集为 DJD_JDJ​。给定新字典时，最小化 ∥Xℓ(w−DJz)∥22+γ∥z∥22\|X_\ell(w-D_Jz)\|_2^2+\gamma\|z\|_2^2∥Xℓ​(w−DJ​z)∥22​+γ∥z∥22​。把范数展开，关于 zzz 的一次项是 −2z⊤DJ⊤Sℓw-2z^\top D_J^\top S_\ell w−2z⊤DJ⊤​Sℓ​w，二次项是 z⊤(DJ⊤SℓDJ+γI)zz^\top(D_J^\top S_\ell D_J+\gamma I)zz⊤(DJ⊤​Sℓ​DJ​+γI)z。令梯度为零即可得到

    (DJ⊤SℓDJ+γI)z=DJ⊤Sℓw.(14)(D_J^\top S_\ell D_J+\gamma I)z=D_J^\top S_\ell w . \tag{14}(DJ⊤​Sℓ​DJ​+γI)z=DJ⊤​Sℓ​w.(14)

    这和剪枝时保住旧系数的输出不同：目标直接是稠密权重的列。若去掉阻尼且使用同一个度量与同一固定字典，旧系数是一个可行解，所以精确求解在这批数据上不会变差。但每个输出列可能选了不同的 JJJ，便有许多小线性系统，求解成本可能成为全流程瓶颈。如果布局约束令许多列共享支撑，可以用一个系数 Gram 分解处理多个右端项。这提供了一个有意思的共同设计空间：结构化掩码可能牺牲单列最优支撑，却让离线重解和在线打包都更规整。

    也不能把拟合误差的下降当成端到端净收益。一次额外系数拟合可能引入更大的值范围，随后在 FP4 中造成难量化的离群项。可以按顺序比较只重拟合字典、字典后再重拟合系数、以及先固定量化字典再拟合系数三个设置；每个设置都用相同实际掩码，统一算量化前后残差、最终 PPL 和额外耗时。如果最后一种改善质量，应当再检查它是否来自按真实部署字典纠正了度量，而不是多使用了校准 token。这些实验不需要放开零位置，也不会改变解码张量尺寸，所以能把收益归到拟合目标上。

    先算端到端的提速上限

    还有一个比「参数少了多少」更有用的估算。设原始每 token 耗时中有比例 fff 用在会被改写的投影，其余操作完全不变。若这些投影本身被加速 sss 倍，每 token 时间按原时间归一后，未动部分仍是 1−f1-f1−f，改写部分变为 f/sf/sf/s；如果还有额外掩码解码和中间写回，再用同一时间单位记为 uuu。整体倍率是

    Gtime=1(1−f)+f/s+u.(15)G_{\rm time}=\frac{1}{(1-f)+f/s+u}. \tag{15}Gtime​=(1−f)+f/s+u1​.(15)

    比如假设某服务的投影只占 45%，投影内核快 1.6 倍，并为额外工作支付原总时间的 3%，整体只能到约 1/(0.55+0.45/1.6+0.03)=1.161/(0.55+0.45/1.6+0.03)=1.161/(0.55+0.45/1.6+0.03)=1.16 倍。把同样的内核放进另一种更受 KV 访问限制的请求，若投影只占 20%，则约为 1/(0.8+0.2/1.6+0.03)=1.051/(0.8+0.2/1.6+0.03)=1.051/(0.8+0.2/1.6+0.03)=1.05 倍。两组输入都是示例，没有用来倒推论文实测的投影占比。它们说明服务端先做性能分解有用：应先找出在短提示、长提示和不同并发下真正占时间的算子，再决定优先优化字典复用还是系数乘法。

    预填充与解码也可以按类似方式拆开。若一条请求原本需要 600 ms 预填充和 400 ms 解码，预填充不变且解码加速 1.24 倍，请求总时长约从 1000 降到 923 ms，约快 1.08 倍；如果预填充反而多花 80 ms，端到端几乎没有改善。反过来，短提示且生成很长的工作负载可能更靠近解码测得的倍率。要选真实部署配置，我会同时记录总延迟、首 token 延迟和稳态每 token 延迟，并用固定请求重放保持生成长度可比。一个形状上测得的有效稀疏后端应该作为测试起点，不能替其他形状承诺速度。

    复现要点：先做小而可判定的对照

    第一步只选一个真实投影，收集相同的校准输入和留出输入。分别算原始 SVD、共同度量 SVD 和逐层度量拟合，在相同秩与真实字节预算下量输出残差。记下 Gram 的条件数、阻尼、保留秩和稀疏掩码。剪系数时同时对比「偏离剪前分解多少」和「偏离稠密目标多少」。两者分离才能解释重拟合是在补剪枝误差，还是把旧的分解误差也压低。量化前后固定支持，记录重拟合前后的系数度量是否一致，避免无意改变两个变量。

    到全模型对照时，固定 checkpoint、tokenizer、分割、上下文长度和评测版本。以附录 A1 和 A2 的设置起步，分别记录因子非零数、打包后的总字节、以及运行时峰值。准确率使用原文注明的字段，保留逐任务分数；若两个基准系列使用不同协议，各自保留完整稠密对照。时间账拆为离线收集、分解、剪枝、重拟合、量化，再单测预填充与解码。第一次解码对照可以复用表 A14 的 batch 1、128 输入 token、100 解码步和热身方案；跑通后再改变长度、并发或内核，每次记录实际发出的 token 数和峰值内存。这样才能识别是在同样的任务上更快，还是少执行了一部分工作。

    本笔记实际核算了秩预算、输入加权截断、单坐标补偿、固定支撑最小二乘，以及图 3、表 3 和表 A14 的比例。小矩阵验算没有调用模型，不是对论文实验的重跑；复现设计是后续可做的对照。

    结论

    DictLLM 提供了一种有说服力的预算分配：先摊销输入侧的公共方向，再让每层自己挑系数，最后分别决定两边用多少位。最有解释力的证据来自剪枝后重拟合：维持原来的稀疏位置和秩，仍然能从相同表示规模里挽回部分质量。FP16 解码实测也表明，在论文给出的形状与后端上，部分容量收益确实转成了吞吐。若要采用这条路线，我会先确认共享是否改善留出样本上的逐层误差，再用实际打包和端到端延迟来决定稀疏模式和精度。摘要的表示倍率只适合作为估算起点。
