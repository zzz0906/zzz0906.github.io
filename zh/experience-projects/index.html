    OSCAR (NeurIPS 2026)
    论文项目代码Hugging Face

    研究动机。 INT2 KV Cache 量化可显著降低长上下文推理显存，但通用旋转与下游注意力不匹配，朴素 INT2 量化常导致准确率崩溃。

    具体贡献。

    1. 主导面向 2-bit KV Cache 量化的离线谱协方差感知旋转方法，校准注意力感知的键值旋转和裁剪阈值。
    2. 推导由注意力诱导的键和值协方差目标，并参与冻结误差代理目标的理论分析。
    3. 设计混合精度推理策略：用 BF16 保留注意力汇聚 token 与近期 token，并以固定旋转量化历史 token。
    4. 参与设计兼容 SGLang、基于 Triton 内核的 INT2 推理路径，在接近 BF16 精度时将 KV 显存约减少 8 倍，大批量吞吐最高提高约 7 倍。
    5. 推动开源采用：首月获得 500 多个 GitHub Star，支持 llama.cpp 本地部署；社区推动 vLLM 集成，使旋转式 KV Cache 量化进入主流推理框架。
    6. 论文发表于 NeurIPS 2026；获 Towards AI、MarkTechPost、ModelScope、量子位和机器之心报道，跨平台阅读量超过 10 万。

    SAW-INT4
    论文代码

    研究动机。 KV Cache 显存是实际大模型服务的重要瓶颈，但许多压缩方法破坏分页缓存布局、规则内存访问或融合注意力内核；我们的目标是在部署约束下实现简单实用的 INT4 方案。

    具体贡献。

    1. 参与面向真实大模型服务的系统感知 INT4 KV Cache 量化研究，发现逐 token INT4 与块对角 Hadamard 旋转可取得实用的精度与效率平衡。
    2. 支持分页 KV Cache 服务中的旋转与量化融合内核集成，保持朴素 INT4 的吞吐，同时恢复其损失的大部分精度。

    10. 诊断并修复多节点训练中的 position_ids、cu_seqlens、注意力掩码及 MoE 分发问题，提升不同模型家族分布式训练的稳定性。

    极高效视频编码系统

    研究动机。 传统编码器（H.264/H.265/AV1）缺乏内容自适应能力，计算与内存成本较高；已有神经压缩器也难以满足 GPU 和移动端实时流媒体需求。我们希望提供面向视频内容的低延迟、领域感知压缩方案。

    具体贡献。

    1. 提出并主导 E²ND-VC（极高效神经领域视频压缩），利用内容感知量化，在标准 GPU 和移动设备上支持低延迟、高质量流媒体。
    2. 设计 Optimal Brain Stride-wise Quantization（OBSQ），依据视频会议、游戏等内容类型选择性压缩神经网络权重，以较小质量损失实现实时 1080p 性能。
    3. 开发基于多内核敏感度的混合位宽量化流水线，在卷积核间动态分配位宽，兼顾关键视觉特征与压缩率。
    4. 与跨职能团队合作实现概念验证流媒体流水线，在保持视觉质量的同时显著降低功耗和带宽使用。

    研究动机。 强化学习智能体可能因对状态与动作分布空间理解不足而偏向某些动作。本研究考察策略梯度网络是否出现神经坍缩，以及该现象对平衡动作选择的影响。

    具体贡献。

    2. 推导并证明策略梯度损失函数的公式与几何性质。
    3. 撰写论文并投稿 NeurIPS。
    扩散模型去噪过程优化
